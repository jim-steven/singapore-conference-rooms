## Usage

Simply open `index.html` in any web browser. The page is fully static and works offline.

### Deploy to GitHub Pages

1. Push this folder to a GitHub repository
2. Go to Settings → Pages
3. Select "Deploy from a branch" and choose `main` branch
4. Your site will be live at `https://yourusername.github.io/singapore-conference-rooms/`
